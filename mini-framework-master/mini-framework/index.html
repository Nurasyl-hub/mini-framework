MiniF

A lightweight JavaScript framework — built from scratch

Virtual DOM

Describe your UI as a JavaScript object tree using h(). MiniF renders it to real DOM and updates it when state changes.

State Management

Flux-style unidirectional flow. Create a store with createStore(state, reducer). Dispatch actions, subscribe to changes.

Routing

Hash-based router syncs the URL with your app state. createRouter().addRoute('/path', fn).start()

Event Handling

Custom event API via Events.on/off/emit/once. Or use inline onClick, onChange in virtual nodes.
